# Local Business Boost

Create a complete, polished, responsive business website for a real small local business.

BUSINESS INFORMATION

Business name: [BUSINESS NAME]
Business type: [BAKERY / CAFE / SALON / TUTOR / etc.]
Location: [AREA, CITY]
Phone: [PHONE NUMBER]
Email: [EMAIL, IF AVAILABLE]
Opening hours: [OPENING HOURS]
Owner-approved website purpose: [SHOWCASE SERVICES / GET INQUIRIES / BOOKINGS / etc.]

The business owner has given permission for this website to be created and showcased as an academic web-development project.

MAIN GOAL

Build a professional website that helps the business establish an online presence and makes it easy for potential customers to understand what the business offers and contact them.

The website should look like a genuine small-business website, not like a generic student template.

REQUIRED PAGES / SECTIONS

1. Home

Create an attractive hero section containing:

Business name

Short, clear tagline

Brief introduction

Primary CTA button such as "Contact Us", "Book Now", "View Services", or "Get in Touch"

A suitable business image or image placeholders using only images that are legally usable

Quick highlights of the business

2. About Us

Include:

Brief business story

What the business offers

What makes it special

Location

Friendly, trustworthy presentation

Do not invent claims, awards, certifications, years of experience, or achievements. Use placeholders where information has not been provided.

3. Products / Services

Create attractive cards for the actual products or services provided by the business.

For each item show:

Name

Short description

Price, ONLY if the owner has provided it

Relevant image if available

Use realistic information supplied by the owner rather than making up business information.

4. Gallery

Create a clean responsive image gallery for:

Business/storefront

Products

Interior

Services

Other owner-approved photos

If actual photos aren't available yet, use clearly marked image placeholders that can easily be replaced later.

5. Testimonials

Create a testimonials section only if the owner provides genuine customer testimonials.

Do NOT fabricate customer reviews.

6. Contact

Include:

Phone

Email

Address/location

Opening hours

Contact/inquiry form

Google Maps/location section or a clear location button if appropriate

Social media links only if the business actually has those accounts

The form should have:

Name

Email/Phone

Message

Submit button

Basic validation

Clear success/error feedback

If a real backend is not configured, make it clear in the UI/code how the form can later be connected to an email service or backend. Do not pretend that messages are actually being delivered if no backend exists.

DESIGN REQUIREMENTS

Create a modern, clean and professional design suitable for a local Indian small business.

Fully responsive on desktop, tablet and mobile

Mobile-first layout

Clear navigation bar

Sticky navigation where appropriate

Good typography

Good spacing

Accessible color contrast

Subtle animations and hover effects

Smooth scrolling

Professional buttons and cards

Avoid excessive animations

Keep the interface simple and easy to use

Use the business's existing logo if the owner provides one.

IMPORTANT:
Do NOT create a new logo if the business does not already have one. Instead, use the business name as text in the header.

Use the owner's preferred brand colors if provided. Otherwise choose a tasteful, professional color palette appropriate for the business type.

TECHNICAL REQUIREMENTS

Use:

React

TypeScript

Tailwind CSS

Modern component-based structure

Keep the code clean and organized.

Create reusable components for:

Navbar

Hero

About

Services/Products

Gallery

Testimonials

Contact

Footer

Buttons/cards where appropriate

Make sure:

Navigation works

All buttons work

Mobile menu works

Forms have validation

Images have alt text

There are no broken links

Layout works at different screen sizes

No unnecessary dependencies are added

No console errors

No placeholder lorem ipsum text remains in the final version

CONTENT RULES

Use concise, natural and professional copy.

Do not invent:

Customer reviews

Business history

Awards

Certifications

Prices

Contact information

Social media accounts

Claims about the business

If information is missing, use clearly labelled placeholders such as:
[ADD BUSINESS PHONE]
[ADD OWNER-APPROVED PHOTO]
[ADD BUSINESS DESCRIPTION]

This allows me to replace the information after speaking with the business owner.

STUDENT PROJECT QUALITY

The final website should look polished enough to demonstrate:

Understanding of responsive web design

HTML/CSS/JS or React concepts

UI/UX decisions

Component-based development

Forms and interactions

Mobile responsiveness

Real-world business requirements

Include a small footer note such as:
"Website created as an academic web development project."

Do not make the website look like an AI-generated template. Make thoughtful design decisions based on the business type and information provided.
